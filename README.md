# Rajmohan Hazowary Portfolio

Personal portfolio built with React, Vite, Tailwind CSS, Framer Motion, and lucide-react. It is configured for the GitHub Pages user repository `USER-00001-IND.github.io`.

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
npm run deploy
```

On Windows PowerShell, use `npm.cmd` if script execution policy blocks `npm`.

## Assets

- Profile photo: `public/profile-photo.jpg`
- Resume download: `public/resume.pdf`

To regenerate the resume from portfolio data:

```bash
node scripts/generate-resume.mjs
```
